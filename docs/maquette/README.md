| `figma-import/*.svg` | Les mêmes écrans, un fichier par page, à importer dans Figma |

## Importer les écrans dans Figma

1. Ouvrir le fichier Figma de la maquette.
2. Glisser-déposer les fichiers `figma-import/*.svg` sur le canvas.
3. Chaque SVG devient un cadre dont les textes et les formes restent modifiables.

Les écrans utilisent les polices **Lora** (titres) et **Inter** (texte), comme la maquette. Les cartes beiges « BDD · … » en bas de chaque écran indiquent les colonnes de la base concernées : elles se suppriment une fois l'écran validé.

Pour les exports de la maquette d'origine (accueil, espace PetSitter, mes annonces, messagerie, mon compte), les déposer ici en `.png` ou `.pdf`.
