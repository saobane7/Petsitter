PetGarden - maquette Figma (13 écrans, 1280 px de large)

Importer dans Figma :
1. Ouvrir (ou créer) un fichier Figma.
2. Sélectionner tous les fichiers .svg de ce dossier et les glisser-déposer sur le canvas.
3. Chaque fichier devient un cadre dont les textes, formes et couleurs restent modifiables.

Polices : Lora (titres) et Inter (texte), disponibles dans Figma.

Écrans :
00 Accueil
01 Connexion
02 Inscription
03 Mes annonces (propriétaire) : statuts Ouverte / Pourvue / Terminée, statistiques
04 Publier une annonce
05 Candidatures reçues : message, note moyenne, valider un gardien
06 Laisser un avis : note de 1 à 5, commentaire, réputation
07 Annonces ouvertes (gardien) : filtres ville et type d'animal
08 Détail d'une annonce et candidature
09 Mes candidatures : En attente / Acceptée / Refusée
10 Profil public du gardien : note moyenne, gardes réalisées
11 Administration : modération des avis, statistiques globales
12 Administration : comptes
